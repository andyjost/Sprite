=======
Support
=======

Questions, bug reports and feature requests go to the `issue tracker`_ of
the repository.

The best bug report is a small Curry program or Python snippet with the
answer you expected and the answer you got. A small file like
``tests/unit_issue103.py`` shows the shape of a unit-test reproducer.

Questions about the Curry language itself, rather than about Sprite, go to
the Curry mailing list, curry@lists.RWTH-Aachen.DE.  The `Curry homepage`_
has the tutorial and the report of the language.

Sprite is developed and maintained by Andy Jost (andy.m.jost@gmail.com).

.. _issue tracker: https://github.com/andyjost/Sprite/issues
.. _Curry homepage: https://www.curry-lang.org/
