Sprite performance history

The nightly performance job runs the benchmark harness of Sprite on the C++ backend on a shared CI runner and appends the records to the branch perf-history of the repository. Timings from shared runners are advisory: read the CPU seconds with the exact counters, and take authoritative numbers from a quiet machine.

Each panel is one item. The line is the chosen metric over time and the number at its end is the last run. A hollow marker: the rewrite steps changed from the previous run, so the program or the compiler changed. A cross on the baseline: the run failed. Hover a panel, or focus it and use the arrow keys, for the date, the commit, the counters, and the status. The Table button lists the last run of every item against the previous one.
